# BrowserOS

**BrowserOS** is a fake operating system that runs entirely in your browser. It is a clean desktop, complete with windows, a taskbar, a file system, and a handful of built-in apps.

## ✨ Features
* **Desktop Experience:** Boot screen, lock screen, draggable/resizable windows, a Start menu, and a taskbar with pinning, running-app indicators, and search.
* **Built-in Apps:** File Explorer, Notes, Calculator, Terminal, Settings, Recycle Bin, and Credits — each with its own icon, right-click menu, and window.
* **Fake File System:** Create, rename, delete, and organize folders and files across Desktop, Documents, Pictures, and Downloads, with full Recycle Bin support.
* **Terminal:** A working command-line with commands like `help`, `ls`, `cd`, `echo`, `whoami`, `date`, and `clear`.
* **Action Center:** Notifications panel with quick-action tiles for theme, search, settings, and terminal, plus a volume slider.
* **Personalization:** Switch between light/dark themes, pick an accent color, and choose from multiple wallpapers.
* **Right-Click Menus:** Context menus throughout the desktop, taskbar, and apps — including on touch devices.
* **Privacy First:** Everything (files, notes, settings, pinned apps) is saved directly in your browser via `localStorage`. Nothing leaves your device.
